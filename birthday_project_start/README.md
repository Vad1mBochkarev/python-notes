# Приложение Birthday: испытательный полигон

Создадим небольшой веб-сервис, в котором пользователь сможет опубликовать имя, фамилию и день рождения. 
Если день рождения пользователя именно сегодня — программа поздравит его с праздником, а если нет — напечатает, сколько дней осталось до дня рождения. На примере этого сервиса разберёмся, как в Django организована работа с формами.
Разверните виртуальное окружение, активируйте его и установите зависимости из requirements.txt. Вся подготовительная работа в проекте уже выполнена: маршруты настроены, шаблоны подготовлены. 


Осмотрите проект, посмотрите, как устроен головной urls.py проекта и файлы с маршрутами приложений; обратите внимание на namespace и name. Загляните во view-функции, осмотрите шаблоны — они хранятся на уровне проекта.
В проекте есть два приложения: 
 - birthday: это приложение, где и будет реализован калькулятор дней рождения;
 - pages: приложение для управления статичными страницами, например — главной страницей приложения.

Выполните встроенные миграции, запустите проект и откройте его в браузере. Пока что там есть только две страницы — «Главная» и «Калькулятор дней рождения». 
На странице «Калькулятор дней рождения» будет размещена веб-форма. Взаимодействие пользователя и сервера будет таким:
 1. Пользователь запрашивает страницу (выполняет GET-запрос) по адресу http://127.0.0.1:8000/birthday/. При запросе к этому адресу вызывается view-функция birthday().
 2. View-функция обрабатывает запрос: создаёт объект формы и передаёт её в шаблон templates/birthday/birthday.html.
 3. Django генерирует HTML-код формы и вставляет его в шаблон, веб-страница отправляется пользователю.
